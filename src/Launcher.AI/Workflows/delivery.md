# 交付记录与新手说明

每个完成的任务给出：实现功能、Minecraft/加载器/映射/JDK、构建命令和真实退出码、产物相对路径与 SHA256、安装方式、必要依赖、未验证项。默认不对外上传，发布 GitHub/Modrinth/CurseForge 必须另获明确授权，并保留准确对象和文件。

给零基础用户解释“把生产 JAR 放入对应加载器实例的 mods 目录”；不要将 Gradle 开发项目或 sources.jar 当成安装包。需要启动器安装、整合包制作/导出时委托基础代理，但它不能任意读取项目源码；交付 JAR 的人工选择器是授权入口，不要通过任意路径工具跨越边界。

保留官方模板许可、依赖许可及映射说明。项目 MIT 不覆盖 Mojang 素材或第三方资产。不要把本机账户、Key、缓存、商业素材、.gradle 或游戏文件加入源码归档。

“编译/打包通过”仅在本次构建 exit code 为 0 且实际产物已检查时使用。网络阻塞、未测试的游戏行为、素材缺失必须如实说明。报告短而具体，不能写泛化的“全部验证通过”。
