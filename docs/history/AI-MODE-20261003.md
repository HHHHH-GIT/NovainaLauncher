# AI Mode 首版 · 2026-10-03

## 使用

顶栏打开 **AI Mode**，输入自己的 DeepSeek API Key，连接后选择官网返回的模型。密钥也可以在 **设置 → AI** 配置。API Key 由 Windows DPAPI 加密，账户登录仍由原有页面完成。

AI 页面使用统一时间线，支持多轮对话、选择题、人工确认、真实安装进度、发送与停止。关闭 AI 会中止本轮请求、追问和未完成的 AI 安装任务；普通下载与已运行 Minecraft 保留。退出后再次进入可继续当前对话，关闭应用或新对话后清空，不保存历史文件。

首次连接与模型列表使用 DeepSeek 官方 `https://api.deepseek.com/models`；会话通过 OpenAI .NET SDK **2.14.0** 调用官方 Responses API。模型优先选择返回列表中的 Pro，否则 Flash，默认 high 推理，支持官网返回的推理档位。模型列表缓存一小时，可手动刷新。

参考：[DeepSeek Responses](https://api-docs.deepseek.com/guides/responses_api/)、[模型列表](https://api-docs.deepseek.com/api/list-models/)、[SDK](https://github.com/openai/openai-dotnet)。SDK 的 Responses/JsonPatch 接口当前标记为实验接口，项目固定版本并集中隔离在 `Launcher.AI`。

## 实现

- 46 DIP 顶栏保持原尺寸。AI 标识和动画滑块采用 `#007AFF → #AF52DE`，普通控件保持原 Apple 蓝。
- 进入时隐藏普通导航、侧栏与弹幕，保留普通页面和滚动状态。极光/标题动画舒缓 2 秒、性能 1.2 秒，关闭动画直接进入。所有动画为一次性位移、缩放或透明度变化。
- API Key、登录令牌与密码不会进入工具状态 DTO。完整会话、请求及推理不写入日志。SDK 负责 SSE；仅 `response.completed` 且完整参数通过校验才执行工具。DeepSeek 的原始 reasoning 内容保存在内存上下文并回传，不展示给用户。
- 共享 `LauncherOperations` 复用游戏/内容安装计划、队列、版本/内容服务、Java、内存和启动链。原下载界面同样使用共享的计划及入队入口。队列支持快照、等待最终结果与按组取消；终态被移除也不影响已获得的等待结果。
- 日常查询、安装、切换、启用/禁用、配置与启动自动执行。删除显示绑定对象的确认卡片；导入/导出通过原生选择器授权路径，覆盖由原生保存对话框确认。没有 Shell、任意 URL、任意路径读取/写入、凭据查询、模组配置正文编辑或对外上传工具。
- 游戏/账户/组件/项目/文件/Java/内容均用主机返回的逻辑 ID。路径限制在授权游戏目录或用户通过选择器指定的位置，拒绝越界及链接。日志读取仅限目标 `logs/latest.log`，脱敏并限制尾部大小；日志与远程描述明确作为不可信数据。
- 每条用户消息最多 24 次模型调用，单次最多 16K 输出 tokens；累计 64K 时等待人工继续。上下文接近容量时要求新对话，不自动删减要求。同轮重复写操作复用结果，避免重复提交。
- Java 下载在进程内复用已完成的相同目标/主版本下载，避免并发等候后重复下载。取消期间初始化来源失败也会清理任务暂存目录。

## AI 界面滚动与输入法修复

- 时间线使用虚拟化像素滚动，长问题卡片可以完整滚动；选项列表不再截获滚轮。底部保留间距，与独立布局的输入区隔开。
- 滚轮采用可中断的柔和缓动，舒缓 180ms、性能 110ms，关闭动画直接滚动；拖动滚动条仍直接响应。
- 只有位于底部时跟随新消息。用户上滚后保留阅读位置，新问题在跟随状态下定位卡片开头，避免只看到末尾。
- 输入法开始组合时立即隐藏占位文字，提交、取消及失焦后重新判断文本；选候选时的 Enter 不触发发送。
- 针对性 WPF 离屏回归通过：三题长卡片底部“继续”按钮可达、与输入框不重叠、分数像素位移、嵌套选项滚轮，以及模拟 IME 开始/更新/提交/失焦的占位状态。
- 离屏图 `artifacts/ui/AI-question-scroll-bottom.png` 已检查。真实输入法候选窗口和人工桌面手感尚未实测，模拟事件不代替桌面验收。
- 更新包目录为 `bin/publish-1.0.0-ai-mode-ui-fix`，ZIP 标签为 `1.0.0-ai-mode-ui-fix`，账户、配置和游戏目录格式保持兼容。
