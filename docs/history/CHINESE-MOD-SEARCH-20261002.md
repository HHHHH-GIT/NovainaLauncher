# 中文模组搜索与图标 · 2026-10-02

- 中文关键词先在本地匹配中文名、英文名、简称与 Mod ID；例如“钠 / 鈉”→ Sodium、“机械动力”→ Create、“暮色森林”→ The Twilight Forest。精确名称优先，其次前缀 / 包含匹配。先请求最匹配的英文关键词，有结果立即显示；其他候选及原中文仅在失败或无结果时依次尝试，避免慢请求拖住已经可用的结果。
- 使用公开的 [HMCL / MC 百科名称表](https://github.com/HMCL-dev/HMCL/blob/main/HMCL/src/main/resources/assets/mod_data.txt)。启动后后台读取 / 更新，缓存保存在数据目录 `downloads/chinese-mod-names.txt`，有效期七天；常见别名内置，首次加载与名称源不可用时仍可使用。未复制 HMCL 搜索代码，发布包不捆绑整份百科数据。
- 名称映射只帮助搜索，结果仍来自当前所选的 Modrinth 或 CurseForge 平台。该平台未发布的模组仍可能只能找到附属或非官方移植；没有把它们冒充为原项目。实测暮色森林原项目选择 CurseForge。
- 列表左侧和文件选择页显示真实模组图标。按可见行异步加载，回收 / 隐藏行取消请求，同时最多两个图标请求。图标文件缓存仍保存在 `downloads/icons`，内存保留冻结的 64px 缩略图；列表继续虚拟化。
- 采用固定版本 SkiaSharp 3.119.1 支持常见 PNG / JPEG / GIF / WebP 解码，解决 Sodium 等热门模组使用 WebP 时 WPF 无法直接显示的问题。图标缺失 / 无法读取时使用统一模组占位图形。小图标使用单次 GET，取消分段探测的额外请求。
- 移除“适合目标游戏”和对应的清除筛选入口、搜索触发逻辑；搜索与目标游戏独立，安装时再选择目标。搜索防抖、取消旧请求、文件版本缓存和手动选择版本保持可用。
