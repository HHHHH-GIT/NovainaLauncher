# 弹窗、整合包导入与任务列表修复

## 修改

- 全局主色按钮改为柔和蓝色渐变，保留白色文字、玻璃高光、按压反馈和键盘焦点。浅色与深色分别配色。
- 确认弹窗增加独立实色表面和一层细边；打开时对整个主窗口做轻度遮罩。沿用原生圆角区域与硬件合成，未开启 WPF 逐像素透明。
- 下载任务面板去掉页内灰色矩形遮罩，改为独立圆角表面、细边和柔影；继续保持 600×480 DIP，连接数量变化不改变尺寸。
- 已完成、失败、已取消的任务可在列表或详情中移除。只删除任务记录，不删除已安装游戏或模组；进行中的任务不能移除。过滤移除后延迟到达的状态消息。
- 版本管理工具栏增加“导入整合包”，下载页原入口保留，共用安装队列。
- 支持多选导入，以及将 ZIP／MRPACK 拖到主窗口自动识别并安装。识别读取归档清单，在后台执行，不因扩展名直接认定格式。
- 支持包含 `modrinth.index.json` 的 MRPACK／ZIP 和包含 CurseForge `manifest.json` 的 ZIP。普通 ZIP、Mod ZIP 或无清单的游戏文件夹压缩包不会误当整合包安装。
- 导入时固定目录与来源设置，同名实例拒绝覆盖；关闭或迁移数据时取消并等待清单读取结束。现有安装器、校验和取消清理逻辑复用。
