# AI 对话视觉与工具分组

## 改动

- 向宣传片中的 AI 页面靠拢：居中星标欢迎页、宽松留白、靠右的蓝紫渐变用户气泡、带星标的助手消息、简洁工具栏和统一输入卡片。普通界面仍使用 Apple 蓝，顶栏仍为 46 DIP。
- 两道问题在足够宽的窗口中并排，小窗口纵排。选项使用主题适配的背景、圆形选择标记和推荐标识，不自动提交推荐答案。
- 连续工具调用自动收进一级展开分组。执行中标题为“正在调用工具”，所有调用结束后为“调用了工具”；助手消息、追问或确认卡片分隔不同调用段。
- 每个调用对应二级执行摘要，展开后显示实际结果。结果转换成有界的中文字段和列表，不显示原始工具参数、JSON、推理或密钥。
- 工具开始、进度、完成、失败和取消使用稳定调用标识关联。停止或异常会结束相应运行状态，避免分组一直显示正在执行。
- 下载整体进度与阶段、文件、连接信息放在对应调用的二级详情中，沿用单调的父进度，不增加第三次展开。普通下载任务的详情入口保持现有方式。
- 保留已有 Markdown、像素滚动、长问题可滚动、输入法组合输入与占位文字处理，以及真实任务进度逻辑。

## 后续细化 · 2026-10-04

- 纯文本不再保留 Markdown 段落的底部外边距，用户气泡的上下内边距统一。
- 工具组从运行变为结束时自动折叠，新调用开始时展开；完成后仍可手动展开查看，后续属性刷新不会把手动展开的详情收起。失败和取消同样结束运行状态。
- 输入区使用顶对齐、单一外部留白，占位文字沿用输入控件的字体与起点，补齐原生文本视图的水平留白；保留 IME 输入时隐藏占位文字的处理。
- Release 构建及现有 WPF 界面回归检查通过。新增检查直接比较气泡上下留白、原生空输入光标矩形与占位文字起点，以及工具组完成后的折叠状态；本次未进行人工桌面操作或真实 API 验收。

## 已回答问题摘要

- 提交全部答案后，问题卡片立即替换为默认折叠的“已回答 N 个问题”。展开后只显示每道题的题目、所选答案及其说明，或者自定义回答。
- 已提交答案固定为独立摘要，原来的候选项、输入框和“继续”按钮移除；自定义输入优先时不保留同时选中的默认选项。发送给 Agent 的答案与摘要使用同一份结果。
- 尚未答完仍保留选择界面；中止时显示“问题已中止”，不会把未提交的选择记成已回答。
- Release 构建与既有 WPF 界面回归通过，检查涵盖真实提问交互的提交、未答完的阻止、自动折叠、展开后只剩答案、选项说明与自定义输入，以及浅深主题离屏截图。本次未进行真实 DeepSeek API 或人工桌面验收。
