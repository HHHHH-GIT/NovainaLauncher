# Novaina 超新星开场动画

2026-10-03。沿用现有像素星环图标，不添加视频文件或新渲染依赖。

## 效果

- 运行时先进入同一个窗口内的开场层，主界面在首帧前已遮挡。
- 星芒淡入并轻微凝聚，闪烁一次，短暂停顿。
- 图标的实际纹理切成像素碎片，向四周飞散；蓝紫光晕和冲击环同步扩张。
- 主界面随爆发从中心向外显露，并渐进淡入；最后清除光晕、碎片和动画裁剪，恢复正常界面。
- 浅深主题分别使用现有主题背景。顶栏高度、圆角、窗口透明度及普通界面主题保持现有设置。

舒缓约 2.8 秒，性能约 1.8 秒；动画关闭或系统减少动画时直接进入主界面。每次运行只播放一次，不在页面切换、最小化恢复时重播。关闭窗口或切换动画档位会结束开场并清理动画。

## 实现

- `src/Launcher.App/Controls/StartupAnimation.xaml(.cs)`：独立开场层、有限动画时钟、像素碎片和显露裁剪。
- `MainWindow` 在构造时准备遮挡，加载时播放；初始化与开场并行，不等待所有 Java 扫描结束才显示界面。
- 主页面缓存预加载延后到开场结束，弹幕在开场期间暂停，避免干扰画面。
- 只使用位移、缩放、透明度和渐变材质；不使用全窗口模糊，不注册持续逐帧渲染循环。结束后停止全部动画时钟并释放碎片。
- 实际截帧发现直接给 Storyboard 绑定部分 Transform 时通道未同步推进，已改为对实际 Transform 启动动画；验证包含显露半径、光晕缩放和碎片位移，而非仅检查透明度。

## 验证

- 构建及现有页面缓存、不重叠、控件渲染回归通过。
- 离屏 HWND 中按实际时间捕获浅、深主题各 36 帧；确认首帧遮挡、闪烁停顿、真实扩散、主界面显露和自动结束。
- 检查性能档时长、关闭档跳过、动画中断及取消后裁剪/碎片清理。
- 截帧和状态结果：`artifacts/startup-smoke/result.json`。动态预览：`novaina-startup-dark.gif`、`novaina-startup-light.gif`。
- 两版 Windows x64 单文件 EXE 已更新，保留既有账户和数据。人工桌面流畅度、不同显卡和显示器 DPI 未在本次验收。

复现离屏捕获：

```powershell
dotnet run --project artifacts/startup-smoke/startup-smoke.csproj -c StartupSmoke
```

使用含 Pillow 的 Python 执行 `artifacts/startup-smoke/make_preview.py` 可以把真实捕获帧编码为 GIF；此脚本只用于预览。
