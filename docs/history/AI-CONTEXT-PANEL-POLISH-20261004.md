# AI 上下文面板与目标编辑修正 · 2026-10-04

## 更新

- 上下文面板移除三行接口与估算说明，改为对话累积、请求用量及手动压缩／新对话的正式提示。分类标题仍标注估算，不把分类值当作精确账单。
- 七个分类使用固定的独立颜色，圆点、百分比和横向进度条一一对应；占比以已用上下文为分母，空分类为零。面板内部可滚动，底部操作不会被高度上限裁掉。
- 新对话、连接、压缩与清除目标按钮增加主题细边框，保留蓝紫强调与键盘焦点。图标按钮沿用轻量样式。
- 目标输入框使用主题背景、前景、光标与选区，加入 12 DIP 圆角和顶部多行布局，修正深色模式的白色矩形。
- 压缩通过独立的服务事件反馈：等待安全边界、执行中、成功及释放量、失败、中止、暂无历史。输入框上方持续展示最近结果，结束后的“就绪”不会覆盖；新对话清空提示。停止与上下文替换的安全规则保持不变。
