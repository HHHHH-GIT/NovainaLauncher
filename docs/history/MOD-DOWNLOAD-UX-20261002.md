# 模组下载选择优化 · 2026-10-02

- 目标游戏下拉框及选中项右侧显示蓝色标签：加载器 · Minecraft 版本。游戏名保持单行，过长名称可悬停查看。
- 获取完整文件列表后在后台建立本地索引，整理空值、空白和加载器大小写，去重文件版本；没有声明版本 / 加载器的文件保留在“未标注”分组。
- 改为“游戏版本、加载器、模组版本”三个联动下拉框。游戏版本按数字版本排序，加载器选项只包含该版本实际提供的类型，模组版本只显示当前组合下的文件。切换不请求网络，跨游戏 / 加载器发布的同一文件可出现在对应分组。
- 首次有匹配项时优先选目标游戏的版本与加载器；无对应项时仍可手动选择其他组合，保留上一轮取消兼容性拦截的行为。目标游戏变化不重新获取文件列表。
- 游戏版本和加载器并排，模组版本占整行，仅显示文件版本名；移除被裁切的第二行。长名称提供悬停提示，下拉面板限制为控件宽度，模组文件列表继续虚拟化。
- 获取文件与整理索引期间显示经典旋转圆圈，完成或失败后隐藏；不可见时停止旋转，加载期间禁用空的筛选控件。
