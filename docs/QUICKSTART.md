# 新手使用指南

## 下载和运行

打开 [最新发布页](https://github.com/HHHHH-GIT/NovainaLauncher/releases/latest)，下载 `NovainaLauncher-版本-win-x64.exe`。这是自包含完整版，无需另外安装 .NET。将它放进一个可写文件夹，双击运行。

`-lite.exe` 是依赖运行环境的版本，需要 .NET 9 Windows Desktop Runtime x64。游戏需要的 Java 另行识别或下载。皮肤 3D 预览需要系统 WebView2 Runtime。

## 第一个游戏

1. **账户**：添加微软、LittleSkin 或离线账户。微软在网页完成授权；LittleSkin 登录后选择角色。单击账户设为当前，双击回首页。
2. **下载**：游戏版本 → 加载器 → 额外配置 → 确认安装。输入游戏名称，提交后通过任务面板查看进度。
3. **版本**：安装完成后选中游戏。已有 `.minecraft` 可直接选择目录扫描，无需重新下载。
4. **设置 → Java**：检查自动选定的 Java，缺少时下载。内存默认智能分配，也可手动调整。
5. **启动**：回到启动页，点击启动游戏。失败时先看日志中的具体阶段与错误。

## 模组和整合包

- 搜索模组后选择游戏版本、加载器与文件，再指定目标游戏。目标不会因浏览而更改当前启动版本。
- Mod 安装版本由用户决定，下载页的版本标签供选择参考；不同 Mod 之间仍可能冲突。
- 整合包可在线下载安装，或导入 ZIP/MRPACK；ZIP 必须是支持的整合包结构，普通任意压缩包不能自动当作游戏。
- 在版本管理的概览可导出整合包。删除游戏和内容需确认，使用回收站。

## AI Mode

顶栏开关进入 AI Mode；首次配置自己的 DeepSeek API Key，测试连接后选择模型。Key 不在 `settings.json` 明文保存。

描述目标即可开始，例如“搜索一个冒险整合包，先让我选择”。AI 会查询真实状态，必要时提问，安装或启动结果在时间线展示。停止会取消本轮未完成的 AI 任务，已运行的 Minecraft 不被结束。

## 数据与备份

默认 EXE 旁有 `data`、`runtime`；游戏放在选定的 `.minecraft`。设置可把 data 复制至新空目录并重启，原数据保留，Java 和游戏不参与迁移。

“导入 settings.json”只导入启动器设置，不是账户备份。账户凭据使用当前 Windows 用户的 DPAPI；跨 Windows 用户/设备复制不能保证仍可登录。提交反馈时只提供脱敏日志，勿上传整个 data。
