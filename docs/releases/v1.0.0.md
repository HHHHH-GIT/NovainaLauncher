## 2026-10-05 更新

- AI 分为基础模式与 Mod 开发工作台，两种模式各自管理会话；历史使用 Windows DPAPI 加密保存，恢复时先核实当前状态，不重放旧调用。
- AI 设置移至独立页面，集中管理 DeepSeek Key、模型和推理档位；普通启动器设置不再包含 AI 配置。
- 工作台内置九份开发指南及官方来源，支持 Fabric/Forge/NeoForge 模板、源码编辑、依赖源码查询、实际 Gradle 构建与 JAR 检查。基础子代理处理游戏、Java、账户等业务准备；默认不启动游戏。
- 输入区新增审批／授权模式。默认审批保留具体操作与项目确认；授权模式须先确认警告，之后开放完整 PowerShell/cmd 与文件工具，取消逐项审批和项目范围限制，权限仍受当前 Windows 用户权限约束。切换会话或退出 AI 后恢复审批模式。
- 改进时间线平滑滚动、虚拟项测量和自动跟随；Markdown 表格支持表头、对齐、换行及深浅主题。
- 上下文压缩使用 LLM 生成结构化交接摘要，另外保留关键操作事实、目标、引用和最近完整交互；长证据使用摘录。失败或取消保留原上下文，界面历史不删除。
- Forge/NeoForge 构建匹配项目要求的 JDK，接入系统代理，改进官方模板回退、有限重试及网络/JDK/编译错误说明。

此前的上下文用量圆环、分类、自动压缩、/compact、/goal、@ 游戏/Java/账户引用，以及工具分组与已回答问题折叠均保留。

## 启动器功能

- 微软、LittleSkin、离线账户，皮肤头像、3D 预览与 PNG 导入。
- 本地版本识别，Java 选择与准备、内存配置；新安装自动下载 Java 可在设置关闭。
- 原版、Forge、Fabric、NeoForge、OptiFine 安装；模组中文搜索与文件版本选择。
- 在线整合包、ZIP/MRPACK 导入、本地导出，Mod／存档／资源包／光影管理。
- 国内镜像优先、来源回退、完整性校验、取消及真实任务进度。
- DeepSeek AI Mode、浅深主题、三档动画、日志弹幕与像素超新星开场。

## 使用与数据

将 EXE 放在可写目录运行，添加账户，下载或选择已有 Minecraft 目录，检查 Java 后启动。Lite 需要 .NET 9 Windows Desktop Runtime x64；3D 预览需要系统 WebView2 Runtime。Java、游戏文件与 AI Key 另行准备，普通启动无需 AI Key。

默认数据在 EXE 旁的 data；现有账户、Java 和游戏目录保持兼容。API Key 和令牌使用当前 Windows 用户 DPAPI 加密。会话目录中包含对话与项目位置，请勿公开或提交这些运行数据。授权模式停止不会撤销已完成的修改。
