## 功能

- 微软、LittleSkin、离线账户；皮肤头像、3D 预览与 PNG 导入。
- 本地版本识别、Java 自动选择与下载、智能内存分配。
- 原版、Forge、Fabric、NeoForge、OptiFine 安装；模组中文搜索、文件版本选择。
- 在线整合包、ZIP/MRPACK 导入、本地导出；Mod、存档、资源包和光影管理。
- 国内镜像优先、来源回退与完整性校验；取消、总进度与连接详情。
- DeepSeek AI Mode：多轮对话、偏好提问、工具调用、安装/启动/日志分析，敏感操作确认。
- 自定义玻璃窗口、浅深主题、动画档位、弹幕日志与像素超新星开场。

## 使用

将完整版 EXE放在可写目录运行，添加账户，下载或选择已有 `.minecraft`，检查 Java 后启动。Lite 另需桌面运行库；3D 预览需要系统 WebView2 Runtime，Java 和游戏文件另行获取。AI 可选，需自备 DeepSeek Key。

数据默认在 EXE旁的 data，令牌经当前 Windows 用户 DPAPI 加密。已有账户、设置、Java 与游戏目录保持兼容。源码内部仍使用历史解决方案名 `iKunLauncherNext.slnx`。
